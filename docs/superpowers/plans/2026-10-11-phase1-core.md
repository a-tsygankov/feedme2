# feedme2 Phase 1 (Core data + web) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A house can sign up with a name and PIN, add cats, log and correct feedings from the web app (online or offline), see each cat's hunger state, change units and settings, and read web, worker and (later) device logs in the hidden console.

**Architecture:** The Worker gains the house data model (D1 migration `0001`), house authentication (15-minute HS256 JWT + rotating 30-day refresh token), CRUD routes for house settings, cats and feedings, a request-scoped D1 log sink, and the hourly prune cron. `shared/` gains the zod API contracts plus the two cross-tier modules the spec insists live in one place: `units` (milligram conversions, entry parsing, knob steps) and `hunger` (six levels from a per-cat interval), each pinned by a JSON vector file under `fixtures/` that the firmware will assert against in Phase 2. The web app gains an auth store, an API client with one automatic refresh-and-retry, a Dexie outbox for feedings that drains when online, the dashboard with a Feed sheet, cat pages with editable history, settings, the cat silhouettes rendered from the feedme masters, and the console rewritten around one merged, filterable log feed.

**Tech Stack:** Hono 4 + `@hono/zod-validator` + `hono/jwt`, Drizzle ORM 0.36 on D1, vitest workers pool; React 18, Vite 5, TanStack Query 5, Dexie 4, react-router 6, Tailwind token layer, shadcn/ui; Python 3 + Pillow for the asset render script; Playwright.

**Spec:** `docs/superpowers/specs/2026-09-20-feedme2-design.md` — §1.1, §1.3, §1.4, §1.5, §1.6, §1.7, §3.1–§3.4, §4.1–§4.4, §4.6, phase table row "1 Core data + web".

## Global Constraints

- Integers only in D1: epoch milliseconds for every timestamp, milligrams for every amount, never REAL. Money and fractions are never stored as floats.
- Primary keys are client-generated UUIDs (TEXT); the server accepts the id the client sends and treats re-sends as idempotent.
- `modified_at` is bumped on every update and is the last-write-wins signal.
- Every house-scoped query takes `houseId` from the auth middleware only, never from the body or query string.
- Tiers: a change under `shared/` bumps webapp and worker; a schema change is a NEW file in `backend/migrations/` (the pre-commit hook and CI enforce both).
- Units: canonical `amountMg`; `enteredUnit` ∈ `g | oz | can`; `enteredValue` is the text the person chose (`"40"`, `"1.5"`, `"1/3"`). 5.5 oz can = 155 922 mg. Conversions live in `shared/src/units.ts` and nowhere else in TypeScript.
- Hunger thresholds (spec §1.6): `fed` < 15 min since feeding; `content` r < 0.50; `peckish` 0.50–0.75; `hungry` 0.75–1.00; `very_hungry` 1.00–1.50; `starving` ≥ 1.50 or never fed, where `r = (now − lastFedAt) / hungryAfterSec`.
- Max 8 cats per house. House name 2–32 chars, unique case-insensitively. PIN 4–12 digits, PBKDF2-SHA256 100 000 iterations, 16-byte salt.
- Access token TTL 15 min, refresh token TTL 30 days, rotated on every use, SHA-256 hashed at rest. `POST /api/auth/test-login` exists only when `ENVIRONMENT !== "production"`.
- Logs: `LogEntry.data` capped at 1 KB JSON at the boundary; retention 7 days or 5 000 rows per house; web batches ≤ 50 entries; `/api/debug/logs` requires a house token.
- No `dark:` Tailwind utilities. All colour through the token layer. Never print secret values.
- Never show a selector for an entity with one option ("Feed all" only with ≥ 2 cats).

## Review Focus

1. **Offline feeding then conflicting edit** — a feeding queued offline, then edited in the web app before the queue drains: the drain must send the create first and the edit second, and the server must accept both. Pinned in Task 14 (`sync-engine.test.ts` "ordered drain").
2. **Clock skew between phone and server** — `fedAt` from a phone whose clock is 10 minutes fast must not render as "fed in −10 min". Hunger math clamps negative ages to 0 and the dashboard shows "just now". Pinned in Task 4 (`hunger.test.ts` "future lastFedAt") and Task 13 (`relative-time.test.ts`).
3. **House-name uniqueness is case-insensitive** — "Mochi House" and "mochi house" are the same house; setup must reject the second and login must find the first by either spelling. Pinned in Task 6 (`auth.test.ts` "case-insensitive name").
4. **A refresh token presented twice** (replay after rotation) must be rejected and must not mint a new pair. Pinned in Task 6 (`auth.test.ts` "rotated token is dead").
5. **Fractions and rounding round-trip** — entering `1/3` can with a 5.5 oz can stores 51 974 mg and formats back as `⅓ can`, not `0.33 can` or `51.97 g`; switching the house unit to grams afterwards shows `52 g`. Pinned in Task 3 (`units.test.ts` "fraction round-trip" and vectors).

```sql
-- 0001: the house data model (spec §3.1). Every timestamp is epoch ms,
-- every amount is milligrams, every id is a client-generated UUID.
-- name_key = lower(name) carries the case-insensitive uniqueness the
-- spec asks for; SQLite's UNIQUE on name alone is case-sensitive.
CREATE TABLE houses (
  id                        TEXT PRIMARY KEY,
  name                      TEXT    NOT NULL,
  name_key                  TEXT    NOT NULL UNIQUE,
  pin_salt                  TEXT    NOT NULL,
  pin_hash                  TEXT    NOT NULL,
  food_unit                 TEXT    NOT NULL DEFAULT 'g' CHECK (food_unit IN ('g', 'oz', 'can')),
  can_size_mg               INTEGER NOT NULL DEFAULT 155922,
  can_fraction_step         TEXT    NOT NULL DEFAULT '1/4' CHECK (can_fraction_step IN ('1/4', '1/3', '1/2')),
  gram_step                 INTEGER NOT NULL DEFAULT 5 CHECK (gram_step IN (1, 5, 10)),
  oz_step_hundredths        INTEGER NOT NULL DEFAULT 25 CHECK (oz_step_hundredths IN (25, 50)),
  hungry_after_sec_default  INTEGER NOT NULL DEFAULT 18000,
  sleep_timeout_sec         INTEGER NOT NULL DEFAULT 300,
  sync_interval_sec         INTEGER NOT NULL DEFAULT 21600,
  timezone                  TEXT    NOT NULL DEFAULT 'UTC',
  created_at                INTEGER NOT NULL,
  modified_at               INTEGER NOT NULL,
  deleted_at                INTEGER
);

CREATE TABLE cats (
  id                    TEXT PRIMARY KEY,
  house_id              TEXT    NOT NULL REFERENCES houses(id),
  name                  TEXT    NOT NULL,
  color                 TEXT    NOT NULL,
  avatar_pose           TEXT    NOT NULL DEFAULT 'C2',
  hungry_after_sec      INTEGER NOT NULL,
  sort_order            INTEGER NOT NULL DEFAULT 0,
  default_amount_mg     INTEGER,
  default_entered_unit  TEXT    CHECK (default_entered_unit IN ('g', 'oz', 'can')),
  default_entered_value TEXT,
  last_fed_at           INTEGER,
  created_at            INTEGER NOT NULL,
  modified_at           INTEGER NOT NULL,
  deleted_at            INTEGER
);
CREATE INDEX cats_house ON cats (house_id, sort_order);

CREATE TABLE feedings (
  id            TEXT PRIMARY KEY,
  house_id      TEXT    NOT NULL REFERENCES houses(id),
  cat_id        TEXT    NOT NULL REFERENCES cats(id),
  fed_at        INTEGER NOT NULL,
  amount_mg     INTEGER NOT NULL CHECK (amount_mg > 0),
  entered_unit  TEXT    NOT NULL CHECK (entered_unit IN ('g', 'oz', 'can')),
  entered_value TEXT    NOT NULL,
  source        TEXT    NOT NULL CHECK (source IN ('device', 'web')),
  device_id     TEXT,
  client_id     TEXT,
  note          TEXT,
  created_at    INTEGER NOT NULL,
  modified_at   INTEGER NOT NULL,
  deleted_at    INTEGER
);
CREATE INDEX feedings_house_time ON feedings (house_id, fed_at DESC);
CREATE INDEX feedings_cat_time ON feedings (house_id, cat_id, fed_at DESC);

-- Opaque rotating refresh tokens (spec §3.2). Only the SHA-256 of the
-- token is stored; rotated_from records the chain for replay detection.
CREATE TABLE refresh_tokens (
  id           TEXT PRIMARY KEY,
  house_id     TEXT    NOT NULL REFERENCES houses(id),
  token_hash   TEXT    NOT NULL UNIQUE,
  created_at   INTEGER NOT NULL,
  expires_at   INTEGER NOT NULL,
  rotated_from TEXT
);
CREATE INDEX refresh_tokens_house ON refresh_tokens (house_id);
```

```ts
    expiresAt: integer("expires_at").notNull(),

export const logEntries = sqliteTable(
  "log_entries",

);
```

```ts
export const FoodUnitSchema = z.enum(["g", "oz", "can"]);
export const CanFractionStepSchema = z.enum(["1/4", "1/3", "1/2"]);
/** Spec §1.7 — the five calm poses offered as identities. */
export const AvatarPoseSchema = z.enum(["A1", "A4", "B1", "C1", "C2"]);

export const MAX_CATS = 8;

/** Eight swatches that survive tinting on both themes and on the dark
 * device screen. The first is the default. */
```

```ts
/**
 * Food amounts (spec §1.5). Canonical storage is integer milligrams;
 * people see and enter grams, ounces or can fractions. This is the ONE
 * TypeScript home for conversions; firmware/src/domain/Units.h mirrors
 * it and both assert fixtures/unit-vectors.json.
 */
import type { CanFractionStep, FoodUnit } from "./api.ts";
export type { CanFractionStep, FoodUnit } from "./api.ts";

export const MG_PER_OZ = 28349.5;
/** 5.5 oz, the standard pet can. */
export const DEFAULT_CAN_MG = 155922;

const FRACTION_CHARS: Record<string, number> = { "¼": 0.25, "½": 0.5, "¾": 0.75, "⅓": 1 / 3, "⅔": 2 / 3 };
export const FRACTION_GLYPHS: Array<[number, string]> = [
  [1 / 4, "¼"], [1 / 3, "⅓"], [1 / 2, "½"], [2 / 3, "⅔"], [3 / 4, "¾"],
];

/** "40", "1.5", "1/3", "1 1/2", "¼" → units; null when not positive or unparsable. */
export function parseEnteredValue(text: string): number | null {
  const t = text.trim();
  if (t === "") return null;
  let total = 0;
  for (const part of t.split(/\s+/)) {
    if (part in FRACTION_CHARS) { total += FRACTION_CHARS[part]!; continue; }
    const frac = /^(\d+)\/(\d+)$/.exec(part);
    if (frac) {
      const den = Number(frac[2]);
      if (den === 0) return null;
      total += Number(frac[1]) / den;
      continue;
    }
    if (!/^\d+(\.\d+)?$/.test(part)) return null;
    total += Number(part);
  }
  return total > 0 ? total : null;
}

function unitMg(unit: FoodUnit, canSizeMg: number): number {
  switch (unit) {
    case "g": return 1000;
    case "oz": return MG_PER_OZ;
    case "can": return canSizeMg;
  }
}

export function toMg(value: number, unit: FoodUnit, canSizeMg: number): number {
  return Math.round(value * unitMg(unit, canSizeMg));
}

export function fromMg(mg: number, unit: FoodUnit, canSizeMg: number): number {
  return mg / unitMg(unit, canSizeMg);
}

/** Nearest glyph when the fractional part is within 2% of one, else null. */
function fractionGlyph(frac: number): string | null {
  for (const [v, glyph] of FRACTION_GLYPHS) if (Math.abs(frac - v) < 0.02) return glyph;
  return null;
}

export function formatAmount(mg: number, unit: FoodUnit, canSizeMg: number): string {
  const v = fromMg(mg, unit, canSizeMg);
  if (unit === "g") return `${Math.round(v)} g`;
  if (unit === "oz") return `${trimZeros(v.toFixed(2))} oz`;
  const whole = Math.floor(v + 1e-9);
  const frac = v - whole;
  const glyph = frac < 0.02 ? "" : fractionGlyph(frac);
  if (glyph === null) return `${trimZeros(v.toFixed(2))} can`;
  const text = whole === 0 ? glyph : `${whole}${glyph}`;
  return `${text} can`;
}

function trimZeros(s: string): string {
  return s.replace(/\.?0+$/, "");
}

export interface StepSettings {
  gramStep: number;
  ozStepHundredths: number;
  canFractionStep: CanFractionStep;
  canSizeMg: number;
}

/** One knob detent / one stepper tap, in mg, for the house's unit. */
export function stepMg(unit: FoodUnit, s: StepSettings): number {
  switch (unit) {
    case "g": return s.gramStep * 1000;
    case "oz": return Math.round((s.ozStepHundredths / 100) * MG_PER_OZ);
    case "can": {
      const den = Number(s.canFractionStep.split("/")[1]);
      return Math.round(s.canSizeMg / den);
    }
  }
}

export function snapToStep(mg: number, step: number): number {
  return Math.max(step, Math.round(mg / step) * step);
}
```

```ts
/**
 * Hunger levels (spec §1.6). r = age / hungryAfter. Six levels, the
 * last two past the interval so a forgotten cat escalates visibly.
 * firmware/src/domain/Hunger.h mirrors this and both assert
 * fixtures/hunger-vectors.json.
 */
export type HungerLevel = "fed" | "content" | "peckish" | "hungry" | "very_hungry" | "starving";

export const HUNGER_ORDER: readonly HungerLevel[] = ["fed", "content", "peckish", "hungry", "very_hungry", "starving"];

/** A feeding counts as "just fed" for this long. */
export const FED_WINDOW_SEC = 900;

export interface HungerState {
  level: HungerLevel;
  /** age / hungryAfter, clamped ≥ 0; Infinity when never fed. */
  ratio: number;
  /** Seconds since the last feeding, clamped ≥ 0; Infinity when never fed. */
  ageSec: number;
}

export function hungerState(nowMs: number, lastFedAtMs: number | null, hungryAfterSec: number): HungerState {
  if (lastFedAtMs === null) {
    return { level: "starving", ratio: Number.POSITIVE_INFINITY, ageSec: Number.POSITIVE_INFINITY };
  }
  // A phone whose clock runs ahead of the server produces a feeding in
  // the future; treat it as "just now" rather than a negative age.
  const ageSec = Math.max(0, (nowMs - lastFedAtMs) / 1000);
  const ratio = ageSec / hungryAfterSec;
  let level: HungerLevel;
  if (ageSec < FED_WINDOW_SEC) level = "fed";
  else if (ratio < 0.5) level = "content";
  else if (ratio < 0.75) level = "peckish";
  else if (ratio < 1.0) level = "hungry";
  else if (ratio < 1.5) level = "very_hungry";
  else level = "starving";
  return { level, ratio, ageSec };
}

/** Semantic colour token per level (webapp/src/styles/tokens/semantic.css). */
export function levelColor(level: HungerLevel): "good" | "warn" | "danger" {
  switch (level) {
    case "fed":
    case "content":
      return "good";
    case "peckish":
      return "warn";
    default:
      return "danger";
  }
}
```

```ts
/**
 * House PIN at rest: PBKDF2-SHA256, 100k iterations, 16-byte salt
 * (spec §3.2). A PIN is short, so the work factor is what stands between
 * a leaked table and every house.
 */
const ITERATIONS = 100_000;

function hex(bytes: ArrayBuffer | Uint8Array): string {
  return [...new Uint8Array(bytes)].map((b) => b.toString(16).padStart(2, "0")).join("");
}
function unhex(s: string): Uint8Array {
  return new Uint8Array(s.match(/../g)!.map((h) => parseInt(h, 16)));
}

async function derive(pin: string, salt: Uint8Array): Promise<string> {
  const key = await crypto.subtle.importKey("raw", new TextEncoder().encode(pin), "PBKDF2", false, ["deriveBits"]);
  const bits = await crypto.subtle.deriveBits({ name: "PBKDF2", hash: "SHA-256", salt, iterations: ITERATIONS }, key, 256);
  return hex(bits);
}

export async function hashPin(pin: string): Promise<{ salt: string; hash: string }> {
  const salt = crypto.getRandomValues(new Uint8Array(16));
  return { salt: hex(salt), hash: await derive(pin, salt) };
}

export async function verifyPin(pin: string, salt: string, hash: string): Promise<boolean> {
  const candidate = await derive(pin, unhex(salt));
  // Constant-time compare: both are 64 hex chars.
  if (candidate.length !== hash.length) return false;
  let diff = 0;
  for (let i = 0; i < hash.length; i++) diff |= candidate.charCodeAt(i) ^ hash.charCodeAt(i);
  return diff === 0;
}
```

```ts
/**
 * House session tokens (spec §3.2): a short-lived HS256 JWT the client
 * keeps in memory, and an opaque refresh token the client persists.
 * The refresh token is stored only as its SHA-256.
 */
import { sign, verify } from "hono/jwt";

export const ACCESS_TTL_SEC = 15 * 60;
export const REFRESH_TTL_MS = 30 * 24 * 60 * 60 * 1000;

export async function signAccessToken(houseId: string, secret: string, nowMs: number = Date.now()): Promise<string> {
  const iat = Math.floor(nowMs / 1000);
  return sign({ sub: houseId, iat, exp: iat + ACCESS_TTL_SEC }, secret, "HS256");
}

export async function verifyAccessToken(token: string, secret: string): Promise<{ houseId: string } | null> {
  try {
    // Algorithm pinned: never let the token choose (alg=none confusion).
    const payload = await verify(token, secret, "HS256");
    return typeof payload["sub"] === "string" ? { houseId: payload["sub"] } : null;
  } catch {
    return null;
  }
}

function base64url(bytes: Uint8Array): string {
  return btoa(String.fromCharCode(...bytes)).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

export function mintRefreshToken(): string {
  return base64url(crypto.getRandomValues(new Uint8Array(32)));
}

export async function hashToken(token: string): Promise<string> {
  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(token));
  return [...new Uint8Array(digest)].map((b) => b.toString(16).padStart(2, "0")).join("");
}
```

```ts
import { and, eq, lt } from "drizzle-orm";
import type { Db } from "../db/client.ts";
import { refreshTokens } from "../db/schema.ts";
import { REFRESH_TTL_MS, hashToken, mintRefreshToken } from "../auth/tokens.ts";

export type ConsumeResult = { houseId: string; id: string } | "unknown" | "expired" | "replayed";

/**
 * Rotation with replay detection: consuming a token deletes it and
 * records its id as `rotatedFrom` on the successor. A token that is
 * presented again after rotation is gone from the table but its id is
 * still referenced by a live successor — that is a replay, and the
 * whole chain is revoked (spec §3.2, review-focus item 4).
 */
export class RefreshTokensRepo {
  constructor(private readonly db: Db) {}

  async issue(houseId: string, nowMs: number, rotatedFrom?: string): Promise<{ token: string; id: string }> {
    const token = mintRefreshToken();
    const id = crypto.randomUUID();
    await this.db.insert(refreshTokens).values({
      id,
      houseId,
      tokenHash: await hashToken(token),
      createdAt: nowMs,
      expiresAt: nowMs + REFRESH_TTL_MS,
      rotatedFrom: rotatedFrom ?? null,
    });
    return { token, id };
  }

  async consume(token: string, nowMs: number): Promise<ConsumeResult> {
    const tokenHash = await hashToken(token);
    const row = await this.db.query.refreshTokens.findFirst({ where: eq(refreshTokens.tokenHash, tokenHash) });
    if (!row) return "unknown";
    if (row.expiresAt <= nowMs) {
      await this.db.delete(refreshTokens).where(eq(refreshTokens.id, row.id));
      return "expired";
    }
    await this.db.delete(refreshTokens).where(eq(refreshTokens.id, row.id));
    return { houseId: row.houseId, id: row.id };
  }

  /** True when `id` is the ancestor of a token still in the table. */
  async wasRotated(id: string): Promise<boolean> {
    const row = await this.db.query.refreshTokens.findFirst({ where: eq(refreshTokens.rotatedFrom, id) });
    return row !== undefined;
  }

  async revokeAll(houseId: string): Promise<void> {
    await this.db.delete(refreshTokens).where(eq(refreshTokens.houseId, houseId));
  }

  async pruneExpired(nowMs: number): Promise<number> {
    const r = await this.db.delete(refreshTokens).where(lt(refreshTokens.expiresAt, nowMs));
    return r.meta.changes;
  }
}
```

```ts
import type { MiddlewareHandler } from "hono";
import type { Bindings } from "../env.ts";
import { verifyAccessToken } from "../auth/tokens.ts";

export type AuthVars = { Variables: { houseId: string } };

/**
 * Bearer access token → c.var.houseId. Downstream handlers and repos
 * take the house id ONLY from here, never from the request — that is
 * the entire multi-tenancy boundary. Uniform 401s: no hint whether the
 * token was missing, malformed or expired.
 */
export function requireHouse(): MiddlewareHandler<{ Bindings: Bindings } & AuthVars> {
  return async (c, next) => {
    const header = c.req.header("Authorization") ?? "";
    const token = header.startsWith("Bearer ") ? header.slice(7) : "";
    const auth = token ? await verifyAccessToken(token, c.env.AUTH_SECRET) : null;
    if (!auth) return c.json({ error: "unauthorized" }, 401);
    c.set("houseId", auth.houseId);
    await next();
  };
}
```

```ts
    return { token, id };
  }

  /** Live token → consumed (turned into a tombstone). */
  async consume(token: string, nowMs: number): Promise<ConsumeResult> {
    const tokenHash = await hashToken(token);
    const row = await this.db.query.refreshTokens.findFirst({ where: eq(refreshTokens.tokenHash, tokenHash) });
    if (!row || row.rotatedFrom === TOMBSTONE) return "unknown";
    if (row.expiresAt <= nowMs) {
      await this.db.delete(refreshTokens).where(eq(refreshTokens.id, row.id));
      return "expired";
    }
    // Keep the hash as a tombstone so a replay can be attributed.
    await this.db
      .update(refreshTokens)
      .set({ rotatedFrom: TOMBSTONE, expiresAt: nowMs + TOMBSTONE_TTL_MS })
      .where(eq(refreshTokens.id, row.id));
    return { houseId: row.houseId, id: row.id };
  }

  async ownerOfTombstone(token: string): Promise<string | null> {
    const tokenHash = await hashToken(token);
    const row = await this.db.query.refreshTokens.findFirst({
      where: and(eq(refreshTokens.tokenHash, tokenHash), eq(refreshTokens.rotatedFrom, TOMBSTONE)),
    });
    return row?.houseId ?? null;
  }

  async revokeAll(houseId: string): Promise<void> {
    await this.db.delete(refreshTokens).where(eq(refreshTokens.houseId, houseId));
  }

  async pruneExpired(nowMs: number): Promise<number> {
    const r = await this.db.delete(refreshTokens).where(lt(refreshTokens.expiresAt, nowMs));
    return r.meta.changes;
  }
}
```

```ts
    return row?.n ?? 0;

      houseId,
      name: input.name,
      color: input.color,
      avatarPose: input.avatarPose,
      hungryAfterSec: input.hungryAfterSec ?? hungryAfterSecDefault,
      sortOrder: n,
      createdAt: nowMs,
      modifiedAt: nowMs,
    });
    return (await this.get(houseId, input.id))!;
  }

  async update(houseId: string, id: string, patch: CatPatch, nowMs: number): Promise<Row | undefined> {
    await this.db.update(cats).set({ ...patch, modifiedAt: nowMs }).where(and(live(houseId), eq(cats.id, id)));
    return this.get(houseId, id);

  async softDelete(houseId: string, id: string, nowMs: number): Promise<void> {
    await this.db.update(cats).set({ deletedAt: nowMs, modifiedAt: nowMs }).where(and(live(houseId), eq(cats.id, id)));
```

```ts
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { CatCreateSchema, CatPatchSchema, MAX_CATS } from "@feedme2/shared";
import type { Bindings } from "../env.ts";
import { db } from "../db/client.ts";
import { requireHouse, type AuthVars } from "../middleware/auth.ts";
import { CatsRepo, toApiCat } from "../repos/cats.ts";
import { HousesRepo } from "../repos/houses.ts";

export const catsRouter = new Hono<{ Bindings: Bindings } & AuthVars>()
  .use("*", requireHouse())
  .get("/", async (c) => {
    const rows = await new CatsRepo(db(c.env.DB)).list(c.var.houseId);
    return c.json({ cats: rows.map(toApiCat) });
  })
  .post("/", zValidator("json", CatCreateSchema), async (c) => {
    const d = db(c.env.DB);
    const repo = new CatsRepo(d);
    const input = c.req.valid("json");
    const existing = await repo.getAny(input.id);
    if (existing) {
      // Idempotent re-send (offline retry) — but never leak another house's cat.
      if (existing.houseId !== c.var.houseId) return c.json({ error: "not found" }, 404);
      return c.json({ cat: toApiCat(existing) }, 200);
    }
    if ((await repo.countLive(c.var.houseId)) >= MAX_CATS) return c.json({ error: `at most ${MAX_CATS} cats` }, 409);
    const house = await new HousesRepo(d).findById(c.var.houseId);
    if (!house) return c.json({ error: "unauthorized" }, 401);
    const row = await repo.create(c.var.houseId, input, house.hungryAfterSecDefault, Date.now());
    return c.json({ cat: toApiCat(row) }, 201);
  })
  .patch("/:id", zValidator("json", CatPatchSchema), async (c) => {
    const row = await new CatsRepo(db(c.env.DB)).update(c.var.houseId, c.req.param("id"), c.req.valid("json"), Date.now());
    if (!row) return c.json({ error: "not found" }, 404);
    return c.json({ cat: toApiCat(row) });
  })
  .delete("/:id", async (c) => {
    const repo = new CatsRepo(db(c.env.DB));
    const row = await repo.get(c.var.houseId, c.req.param("id"));
    if (!row) return c.json({ error: "not found" }, 404);
    if ((await repo.countLive(c.var.houseId)) <= 1) return c.json({ error: "a house keeps at least one cat" }, 409);
    await repo.softDelete(c.var.houseId, row.id, Date.now());
    return c.body(null, 204);
  });
```

```ts
import type { Feeding, FeedingCreate, FeedingPatch } from "@feedme2/shared";
import type { Db } from "../db/client.ts";
import { cats, feedings } from "../db/schema.ts";

type Row = typeof feedings.$inferSelect;

export function toApiFeeding(r: Row): Feeding {
  return {
    id: r.id, houseId: r.houseId, catId: r.catId, fedAt: r.fedAt, amountMg: r.amountMg,
    enteredUnit: r.enteredUnit, enteredValue: r.enteredValue, source: r.source,
    deviceId: r.deviceId, clientId: r.clientId, note: r.note, createdAt: r.createdAt, modifiedAt: r.modifiedAt,
  };

export interface PageQuery { catId?: string; from?: number; to?: number; cursor?: number; limit: number }

export class FeedingsRepo {
  constructor(private readonly db: Db) {}

  async page(houseId: string, q: PageQuery): Promise<{ items: Row[]; nextCursor: number | null }> {
    const conds = [eq(feedings.houseId, houseId), isNull(feedings.deletedAt)];
    if (q.catId) conds.push(eq(feedings.catId, q.catId));
    if (q.from !== undefined) conds.push(gte(feedings.fedAt, q.from));
    if (q.to !== undefined) conds.push(lte(feedings.fedAt, q.to));
    if (q.cursor !== undefined) conds.push(lt(feedings.fedAt, q.cursor));
    const rows = await this.db.query.feedings.findMany({ where: and(...conds), orderBy: [desc(feedings.fedAt), desc(feedings.createdAt)], limit: q.limit + 1 });
    const items = rows.slice(0, q.limit);
    const nextCursor = rows.length > q.limit ? items[items.length - 1]!.fedAt : null;
    return { items, nextCursor };
  }

  get(houseId: string, id: string): Promise<Row | undefined> {
    return this.db.query.feedings.findFirst({ where: and(eq(feedings.houseId, houseId), eq(feedings.id, id), isNull(feedings.deletedAt)) });
  }

  /** Inserts the items whose id is new; returns the ids actually inserted. */
  async createMany(
    houseId: string,
    items: FeedingCreate[],
    source: "web" | "device",
    origin: { clientId?: string; deviceId?: string },
    nowMs: number,
  ): Promise<string[]> {
    if (items.length === 0) return [];
    const existing = await this.db.query.feedings.findMany({ where: inArray(feedings.id, items.map((i) => i.id)), columns: { id: true } });
    const seen = new Set(existing.map((e) => e.id));
    const fresh = items.filter((i, idx) => !seen.has(i.id) && items.findIndex((j) => j.id === i.id) === idx);
    if (fresh.length === 0) return [];
    await this.db.insert(feedings).values(
      fresh.map((i) => ({
        id: i.id, houseId, catId: i.catId, fedAt: i.fedAt, amountMg: i.amountMg, enteredUnit: i.enteredUnit,
        enteredValue: i.enteredValue, source, deviceId: origin.deviceId ?? null, clientId: origin.clientId ?? null,
        note: i.note ?? null, createdAt: nowMs, modifiedAt: nowMs,
      })),
    );
    return fresh.map((i) => i.id);
  }

  async update(houseId: string, id: string, patch: FeedingPatch, nowMs: number): Promise<Row | undefined> {
    await this.db.update(feedings).set({ ...patch, modifiedAt: nowMs }).where(and(eq(feedings.houseId, houseId), eq(feedings.id, id), isNull(feedings.deletedAt)));
    return this.get(houseId, id);
  }

  async softDelete(houseId: string, id: string, nowMs: number): Promise<void> {
    await this.db.update(feedings).set({ deletedAt: nowMs, modifiedAt: nowMs }).where(and(eq(feedings.houseId, houseId), eq(feedings.id, id)));
  }

  /**
   * The cat row carries last_fed_at and the "default for next feeding"
   * (spec §1.5) so the device's single state read needs no join.
   * Recomputed from the newest live feeding after every write.
   */
  async refreshCatDefaults(houseId: string, catId: string, nowMs: number): Promise<void> {
    const latest = await this.db.query.feedings.findFirst({
      where: and(eq(feedings.houseId, houseId), eq(feedings.catId, catId), isNull(feedings.deletedAt)),
      orderBy: [desc(feedings.fedAt), desc(feedings.createdAt)],
    });
    await this.db
      .update(cats)
      .set({
        lastFedAt: latest?.fedAt ?? null,
        defaultAmountMg: latest?.amountMg ?? null,
        defaultEnteredUnit: latest?.enteredUnit ?? null,
        defaultEnteredValue: latest?.enteredValue ?? null,
        modifiedAt: nowMs,
      })
      .where(and(eq(cats.houseId, houseId), eq(cats.id, catId)));
  }
}
```

```ts
 * Per-request store so the logger can attribute worker entries to the

import type { LogEntry } from "@feedme2/shared";

export interface RequestStore {
  houseId: string | null;
  pending: LogEntry[];
}

const storage = new AsyncLocalStorage<RequestStore>();

export function runWithRequestContext<T>(fn: () => Promise<T>): Promise<T> {
  return storage.run({ houseId: null, pending: [] }, fn);
}

export function currentRequest(): RequestStore | undefined {
  return storage.getStore();
```

```ts
import { and, desc, eq, gte, lt, or, sql } from "drizzle-orm";
import type { DebugLogsQuery, LogEntry } from "@feedme2/shared";
import type { Db } from "../db/client.ts";
import { logEntries } from "../db/schema.ts";

export const LOG_RETENTION_MS = 7 * 24 * 60 * 60 * 1000;
export const LOG_ROWS_PER_HOUSE = 5000;

export class LogsRepo {
  constructor(private readonly db: Db) {}

  async insertMany(
    houseId: string | null,
    entries: LogEntry[],
    origin: { clientId?: string; deviceId?: string },
    nowMs: number,
  ): Promise<void> {
    if (entries.length === 0) return;
    await this.db.insert(logEntries).values(
      entries.map((e) => ({
        id: crypto.randomUUID(), houseId, source: e.source, deviceId: e.deviceId ?? origin.deviceId ?? null,
        clientId: e.clientId ?? origin.clientId ?? null, ts: e.ts, level: e.level, msg: e.msg,
        data: e.data ? JSON.stringify(e.data) : null, createdAt: nowMs,
      })),
    );
  }

  async query(houseId: string, q: DebugLogsQuery): Promise<LogEntry[]> {
    const conds = [eq(logEntries.houseId, houseId)];
    if (q.source) conds.push(eq(logEntries.source, q.source));
    if (q.level) conds.push(eq(logEntries.level, q.level));
    if (q.since !== undefined) conds.push(gte(logEntries.ts, q.since));
    const rows = await this.db.query.logEntries.findMany({ where: and(...conds), orderBy: [desc(logEntries.ts), desc(logEntries.createdAt)], limit: q.limit });
    return rows.map((r) => ({
      ts: r.ts, level: r.level, source: r.source, msg: r.msg,
      ...(r.data ? { data: JSON.parse(r.data) as Record<string, unknown> } : {}),
      ...(r.deviceId ? { deviceId: r.deviceId } : {}),
      ...(r.clientId ? { clientId: r.clientId } : {}),
    }));
  }

  /** Age cap, then per-house row cap (keep the newest 5 000). */
  async prune(nowMs: number): Promise<number> {
    const aged = await this.db.delete(logEntries).where(lt(logEntries.ts, nowMs - LOG_RETENTION_MS));
    const overflow = await this.db.run(sql`
      DELETE FROM log_entries WHERE id IN (
        SELECT id FROM (
          SELECT id, row_number() OVER (PARTITION BY house_id ORDER BY ts DESC) AS rn
          FROM log_entries WHERE house_id IS NOT NULL
        ) WHERE rn > ${LOG_ROWS_PER_HOUSE}
      )`);
    return aged.meta.changes + (overflow.meta.changes ?? 0);
  }
}
```

```ts
import { verifyAccessToken } from "./auth/tokens.ts";

import { authRouter } from "./routes/auth.ts";

import { feedingsRouter } from "./routes/feedings.ts";

const app = new Hono<{ Bindings: Bindings } & AuthVars>();

// Request log + persistence. The line is attributed to the house whose
// token signed the request (read here, independently of requireHouse,
// so even a 401 or a public route is attributed when a token is sent).
// Skips the health probe and /api/debug/* so the console polling for
// logs does not generate the logs it displays.
app.use("*", async (c, next) => {
  const start = Date.now();
  const path = new URL(c.req.url).pathname;
  const skip = path === "/api/health" || path.startsWith("/api/debug");
  const header = c.req.header("Authorization") ?? "";
  const token = header.startsWith("Bearer ") ? header.slice(7) : "";
  const auth = token ? await verifyAccessToken(token, c.env.AUTH_SECRET) : null;
  await runWithRequestContext(async () => {
    const store = currentRequest()!;
    store.houseId = auth?.houseId ?? null;
    // Hono's compose() converts a thrown handler error into a response
    // and sets c.error; a try/catch here would never see it.
    await next();
    if (!skip) {
      if (c.error) {
        log.error("request failed", { method: c.req.method, path, durationMs: Date.now() - start, error: c.error.message });
      } else {
        log.info("request", { method: c.req.method, path, status: c.res.status, durationMs: Date.now() - start });
      }
    }
    if (store.pending.length > 0) {
      const entries = store.pending.splice(0);
      c.executionCtx.waitUntil(new LogsRepo(db(c.env.DB)).insertMany(store.houseId, entries, {}, Date.now()));
    }
  });
});

app.get("/api/health", (c) => c.json({ ok: true, env: c.env.ENVIRONMENT, ts: Date.now() }));

app.route("/api/version", versionRouter);
app.route("/api/debug", debugRouter);
app.route("/api/auth", authRouter);
app.route("/api/house", houseRouter);
app.route("/api/cats", catsRouter);
app.route("/api/feedings", feedingsRouter);
app.route("/api/logs", logsRouter);

export { app };

export default {
  fetch: app.fetch,
  // Hourly ([triggers] in wrangler.toml): log retention and expired
  // refresh tokens (spec §3.4).
  async scheduled(_event, env, ctx) {
    ctx.waitUntil(runHousekeeping(env));
  },
} satisfies ExportedHandler<Bindings>;
```

```ts
 * feeding history say "logged from this phone" with no person identity. */
const KEY = "feedme2:clientId";

export function getClientId(storage: Pick<Storage, "getItem" | "setItem"> = localStorage): string {
  try {
    const existing = storage.getItem(KEY);
    if (existing) return existing;
    const id = crypto.randomUUID();
    storage.setItem(KEY, id);
    return id;
  } catch {
    return "ephemeral";
  }
}
```

```ts
/**
 * House session (spec §3.2, gigsy's shape): the access token lives in
 * memory only; the refresh token and a house snapshot persist in
 * localStorage so the installed PWA reopens signed in. Three refresh
 * outcomes, because conflating "the server said no" with "no network"
 * once turned a flaky connection into a sign-out.
 */
import { HouseSchema, TokensResponseSchema, type House, type TokensResponse } from "@feedme2/shared";

export type AuthSnapshot = { status: "signedOut" } | { status: "signedIn"; house: House };
export type RefreshOutcome = { ok: true } | { ok: false; reason: "rejected" | "unreachable" };

export interface AuthStore {
  subscribe(listener: () => void): () => void;
  getSnapshot(): AuthSnapshot;
  applyTokens(t: TokensResponse): void;
  updateHouse(house: House): void;
  signOut(): void;
  /** null when missing or within a minute of expiry — callers refresh. */
  getAccessToken(): string | null;
  getRefreshToken(): string | null;
  refresh(): Promise<RefreshOutcome>;
}

interface Deps {
  storage: Pick<Storage, "getItem" | "setItem" | "removeItem">;
  fetchFn: typeof fetch;
  now: () => number;
}

const REFRESH_KEY = "feedme2:refresh";
const HOUSE_KEY = "feedme2:house";
const EARLY_MS = 60_000;

export function createAuthStore(deps: Deps): AuthStore {
  let accessToken: string | null = null;
  let accessExpiresAt = 0;
  let snapshot: AuthSnapshot = { status: "signedOut" };
  let inflight: Promise<RefreshOutcome> | null = null;
  const listeners = new Set<() => void>();

  const read = (k: string) => { try { return deps.storage.getItem(k); } catch { return null; } };
  const write = (k: string, v: string | null) => { try { v === null ? deps.storage.removeItem(k) : deps.storage.setItem(k, v); } catch { /* private mode */ } };

  const storedHouse = read(HOUSE_KEY);
  if (read(REFRESH_KEY) && storedHouse) {
    const parsed = HouseSchema.safeParse(JSON.parse(storedHouse));
    if (parsed.success) snapshot = { status: "signedIn", house: parsed.data };
  }

  function set(next: AuthSnapshot): void {
    snapshot = next;
    for (const l of listeners) l();
  }

  const store: AuthStore = {
    subscribe(l) { listeners.add(l); return () => void listeners.delete(l); },
    getSnapshot: () => snapshot,
    applyTokens(t) {
      accessToken = t.accessToken;
      accessExpiresAt = deps.now() + t.expiresIn * 1000;
      write(REFRESH_KEY, t.refreshToken);
      write(HOUSE_KEY, JSON.stringify(t.house));
      set({ status: "signedIn", house: t.house });
    },
    updateHouse(house) {
      write(HOUSE_KEY, JSON.stringify(house));
      set({ status: "signedIn", house });
    },
    signOut() {
      accessToken = null;
      accessExpiresAt = 0;
      write(REFRESH_KEY, null);
      write(HOUSE_KEY, null);
      set({ status: "signedOut" });
    },
    getAccessToken() {
      if (accessToken === null || deps.now() >= accessExpiresAt - EARLY_MS) return null;
      return accessToken;
    },
    getRefreshToken: () => read(REFRESH_KEY),
    refresh() {
      // One refresh at a time: concurrent 401s must not each rotate.
      if (inflight) return inflight;
      inflight = (async (): Promise<RefreshOutcome> => {
        const refreshToken = read(REFRESH_KEY);
        if (!refreshToken) { store.signOut(); return { ok: false, reason: "rejected" }; }
        let res: Response;
        try {
          res = await deps.fetchFn("/api/auth/refresh", { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify({ refreshToken }) });
        } catch {
          return { ok: false, reason: "unreachable" };
        }
        if (res.status === 401 || res.status === 400) { store.signOut(); return { ok: false, reason: "rejected" }; }
        if (!res.ok) return { ok: false, reason: "unreachable" };
        const parsed = TokensResponseSchema.safeParse(await res.json());
        if (!parsed.success) return { ok: false, reason: "unreachable" };
        store.applyTokens(parsed.data);
        return { ok: true };
      })().finally(() => { inflight = null; });
      return inflight;
    },
  };
  return store;
}

export const authStore: AuthStore = createAuthStore({ storage: localStorage, fetchFn: (...a) => fetch(...a), now: Date.now });
```

```ts
/**
 * The only place the webapp calls fetch for /api/*. Adds the bearer
 * and client id, refreshes a stale token before the call, retries once
 * after a 401, and turns every other non-2xx into ApiError.
 */
import {
  CatSchema, FeedingSchema, FeedingsPageSchema, HouseSchema, DebugLogsResponseSchema, TokensResponseSchema,
  type Cat, type CatCreate, type CatPatch, type DebugLogsQuery, type Feeding, type FeedingCreate, type FeedingPatch,
  type FeedingsPage, type House, type HousePatch, type LogEntry, type TokensResponse,
} from "@feedme2/shared";
import { z } from "zod";
import { authStore } from "./auth-store.ts";
import { getClientId } from "./client-id.ts";

export class ApiError extends Error {
  constructor(readonly status: number, readonly body: unknown) {
    super(`API ${status}`);
  }
}

interface Deps {
  fetchFn: typeof fetch;
  auth: { getAccessToken(): string | null; refresh(): Promise<{ ok: boolean }> };
  clientId: string;
}

export function createApiFetch(deps: Deps) {
  return async function apiFetch(path: string, init: RequestInit = {}): Promise<Response> {
    let token = deps.auth.getAccessToken();
    if (token === null) {
      const r = await deps.auth.refresh();
      if (!r.ok) throw new ApiError(401, { error: "unauthorized" });
      token = deps.auth.getAccessToken();
    }
    const send = (t: string | null) =>
      deps.fetchFn(path, {
        ...init,
        headers: {
          "content-type": "application/json",
          ...(t ? { authorization: `Bearer ${t}` } : {}),
          "x-client-id": deps.clientId,
          ...(init.headers ?? {}),
        },
      });
    let res = await send(token);
    if (res.status === 401) {
      const r = await deps.auth.refresh();
      if (!r.ok) throw new ApiError(401, { error: "unauthorized" });
      res = await send(deps.auth.getAccessToken());
    }
    if (!res.ok) {
      let body: unknown = null;
      try { body = await res.json(); } catch { /* no body */ }
      throw new ApiError(res.status, body);
    }
    return res;
  };
}

export const apiFetch = createApiFetch({ fetchFn: (...a) => fetch(...a), auth: authStore, clientId: getClientId() });

/** Public (no token) POST used by setup/login/test-login. */
async function publicPost<T>(path: string, body: unknown, schema: z.ZodType<T>): Promise<T> {
  const res = await fetch(path, { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify(body) });
  if (!res.ok) {
    let b: unknown = null;
    try { b = await res.json(); } catch { /* no body */ }
    throw new ApiError(res.status, b);
  }
  return schema.parse(await res.json());
}

async function json<T>(res: Response, schema: z.ZodType<T>): Promise<T> {
  return schema.parse(await res.json());
}
```

```python
#!/usr/bin/env python3
"""Render the cat masters into the sizes each tier needs. Requires Pillow."""
from __future__ import annotations
from pathlib import Path
from PIL import Image

ROOT = Path(__file__).resolve().parents[2]
SRC = ROOT / "assets" / "cats"
WEB = ROOT / "webapp" / "public" / "cats"
POSES = ["A1", "A2", "A3", "A4", "B1", "B2", "B3", "B4", "C1", "C2", "C3", "C4"]
WEB_PX = 256
MARGIN = 0.06


def square_crop(img: Image.Image) -> Image.Image:
    img = img.convert("RGBA")
    bbox = img.getchannel("A").getbbox()
    if bbox is None:
        raise SystemExit(f"empty alpha in {img.filename}")
    img = img.crop(bbox)
    side = int(max(img.size) * (1 + 2 * MARGIN))
    canvas = Image.new("RGBA", (side, side), (0, 0, 0, 0))
    canvas.paste(img, ((side - img.width) // 2, (side - img.height) // 2), img)
    return canvas


def main() -> None:
    WEB.mkdir(parents=True, exist_ok=True)
    for pose in POSES:
        master = Image.open(SRC / f"{pose}.png")
        sq = square_crop(master).resize((WEB_PX, WEB_PX), Image.LANCZOS)
        # Alpha mask: colour is irrelevant for mask-image, keep it black.
        out = Image.new("RGBA", sq.size, (0, 0, 0, 0))
        out.putalpha(sq.getchannel("A"))
        out.save(WEB / f"{pose}.png", optimize=True)
        print(f"  cats/{pose}.png")


if __name__ == "__main__":
    main()
```

```tsx
import { levelColor, type HungerLevel } from "@feedme2/shared";

interface Props {
  ratio: number;
  level: HungerLevel;
  size?: number;
  children?: ReactNode;
}

const COLOR: Record<ReturnType<typeof levelColor>, string> = {
  good: "var(--good-text)",
  warn: "var(--warn-value)",
  danger: "var(--danger-text)",
};

/** A ring that empties as the cat gets hungrier; full = just fed. */
export function HungerRing({ ratio, level, size = 120, children }: Props) {
  const stroke = 8;
  const r = (size - stroke) / 2;
  const c = 2 * Math.PI * r;
  const fill = Number.isFinite(ratio) ? Math.max(0, 1 - Math.min(ratio, 1)) : 0;
  const pulse = level === "starving" ? "animate-pulse" : "";
  return (
    <div className="relative" style={{ width: size, height: size }} data-testid="hunger-ring" data-level={level}>
      <svg width={size} height={size} className={`absolute inset-0 -rotate-90 ${pulse}`} aria-hidden>
        <circle cx={size / 2} cy={size / 2} r={r} fill="none" stroke="var(--border-default)" strokeWidth={stroke} />
        <circle cx={size / 2} cy={size / 2} r={r} fill="none" stroke={COLOR[levelColor(level)]} strokeWidth={stroke}
          strokeLinecap="round" strokeDasharray={c} strokeDashoffset={c * (1 - fill)} />
      </svg>
      <div className="absolute inset-0 flex items-center justify-center">{children}</div>
    </div>
  );
}
```

```ts
export function relativeTime(nowMs: number, thenMs: number | null): string {
  if (thenMs === null) return "never";
  const s = Math.max(0, Math.floor((nowMs - thenMs) / 1000));
  if (s < 60) return "just now";
  const m = Math.floor(s / 60);
  if (m < 60) return `${m} m ago`;
  const h = Math.floor(m / 60);
  if (h < 24) return m % 60 === 0 ? `${h} h ago` : `${h} h ${m % 60} m ago`;
  const d = Math.floor(h / 24);
  return h % 24 === 0 ? `${d} d ago` : `${d} d ${h % 24} h ago`;
}
```

```ts
import { FRACTION_GLYPHS, fromMg, snapToStep, stepMg, type FoodUnit, type StepSettings } from "@feedme2/shared";

export function stepAmount(mg: number, dir: 1 | -1, unit: FoodUnit, s: StepSettings): number {
  const step = stepMg(unit, s);
  return snapToStep(mg + dir * step, step);
}

/** What to record as enteredUnit/enteredValue for a stepped amount. */
export function textForMg(mg: number, unit: FoodUnit, s: StepSettings): { enteredUnit: FoodUnit; enteredValue: string } {
  const v = fromMg(mg, unit, s.canSizeMg);
  if (unit === "g") return { enteredUnit: "g", enteredValue: String(Math.round(v)) };
  if (unit === "oz") return { enteredUnit: "oz", enteredValue: String(Number(v.toFixed(2))) };
  const whole = Math.floor(v + 1e-9);
  const frac = v - whole;
  const glyph = FRACTION_GLYPHS.find(([f]) => Math.abs(f - frac) < 0.02);
  const fracText = glyph ? { "¼": "1/4", "⅓": "1/3", "½": "1/2", "⅔": "2/3", "¾": "3/4" }[glyph[1]] : null;
  if (frac < 0.02) return { enteredUnit: "can", enteredValue: String(whole) };
  if (!fracText) return { enteredUnit: "can", enteredValue: String(Number(v.toFixed(2))) };
  return { enteredUnit: "can", enteredValue: whole === 0 ? fracText : `${whole} ${fracText}` };
}
```

```ts
}
```

```ts
/**
 * Feedings are the one thing a person must be able to log with no
 * network (spec §4.2). Writes go into the Dexie outbox first; this
 * engine drains it in order whenever the app is online and visible.
 * A network failure stops the drain and keeps the op. A 4xx other
 * than 401 drops the op (the server will never accept it) and logs
 * why. A 401 stops: the api client already tried a refresh.
 */
import type { EntityTable } from "dexie";
import type { FeedingCreate, FeedingPatch } from "@feedme2/shared";
import { ApiError } from "./api-client.ts";
import type { OutboxOp, OutboxRow } from "./db.ts";

export interface DrainResult { sent: number; dropped: number; stopped: boolean }
export type SyncStatus = "idle" | "syncing" | "offline" | "error";
export interface SyncSnapshot { pending: number; status: SyncStatus }

interface Deps {
  outbox: EntityTable<OutboxRow, "seq">;
  api: {
    createFeedings(items: FeedingCreate[]): Promise<unknown>;
    patchFeeding(id: string, patch: FeedingPatch): Promise<unknown>;
    deleteFeeding(id: string): Promise<unknown>;
  };
  now: () => number;
  log: { info(m: string, d?: Record<string, unknown>): void; warn(m: string, d?: Record<string, unknown>): void; error(m: string, d?: Record<string, unknown>): void };
}

export function createSyncEngine(deps: Deps) {
  let snapshot: SyncSnapshot = { pending: 0, status: "idle" };
  let draining: Promise<DrainResult> | null = null;
  const listeners = new Set<() => void>();
  const set = (s: Partial<SyncSnapshot>) => { snapshot = { ...snapshot, ...s }; for (const l of listeners) l(); };
  const refreshPending = async () => set({ pending: await deps.outbox.count() });
  void refreshPending();

  async function send(op: OutboxRow): Promise<void> {
    switch (op.kind) {
      case "create": await deps.api.createFeedings([op.payload as FeedingCreate]); return;
      case "patch": await deps.api.patchFeeding(op.feedingId, op.payload as FeedingPatch); return;
      case "delete": await deps.api.deleteFeeding(op.feedingId); return;
    }
  }

  async function drainOnce(): Promise<DrainResult> {
    set({ status: "syncing" });
    const result: DrainResult = { sent: 0, dropped: 0, stopped: false };
    const ops = await deps.outbox.orderBy("seq").toArray();
    for (const op of ops) {
      try {
        await send(op);
        await deps.outbox.delete(op.seq!);
        result.sent++;
      } catch (err) {
        if (err instanceof ApiError && err.status !== 401 && err.status < 500) {
          deps.log.error("sync op dropped", { kind: op.kind, feedingId: op.feedingId, status: err.status, body: err.body });
          await deps.outbox.delete(op.seq!);
          result.dropped++;
          continue;
        }
        result.stopped = true;
        break;
      }
    }
    await refreshPending();
    set({ status: result.stopped ? (snapshot.pending > 0 ? "offline" : "error") : "idle" });
    return result;
  }

  return {
    subscribe(l: () => void) { listeners.add(l); return () => void listeners.delete(l); },
    getSnapshot: () => snapshot,
    async enqueue(op: OutboxOp): Promise<void> {
      await deps.outbox.add({ kind: op.kind, feedingId: op.feedingId, payload: op.payload, createdAt: deps.now() });
      await refreshPending();
    },
    drain(): Promise<DrainResult> {
      if (draining) return draining;
      draining = drainOnce().finally(() => { draining = null; });
      return draining;
    },
  };
}

export type SyncEngine = ReturnType<typeof createSyncEngine>;
```

```ts
import { MG_PER_OZ, type HousePatch, type HouseSettings } from "@feedme2/shared";

/** Spec Q5 default: 3 / 5.5 / 12.5 oz plus custom grams. */
export const CAN_PRESETS = [
  { label: "3 oz", mg: Math.round(3 * MG_PER_OZ) },
  { label: "5.5 oz", mg: Math.round(5.5 * MG_PER_OZ) },
  { label: "12.5 oz", mg: Math.round(12.5 * MG_PER_OZ) },
] as const;

export interface SettingsForm extends Omit<HouseSettings, "hungryAfterSecDefault" | "canSizeMg"> {
  hungryAfterHours: number;
  canSizeGrams: number;
}

export function formFromSettings(s: HouseSettings): SettingsForm {
  const { hungryAfterSecDefault, canSizeMg, ...rest } = s;
  return { ...rest, hungryAfterHours: hungryAfterSecDefault / 3600, canSizeGrams: canSizeMg / 1000 };
}

/** Only the keys whose value differs from `current`, so a PATCH is minimal. */
export function settingsPatchFromForm(form: SettingsForm, current: HouseSettings): HousePatch {
  const next: HouseSettings = {
    ...current,
    foodUnit: form.foodUnit, canFractionStep: form.canFractionStep, gramStep: form.gramStep, ozStepHundredths: form.ozStepHundredths,
    sleepTimeoutSec: form.sleepTimeoutSec, syncIntervalSec: form.syncIntervalSec, timezone: form.timezone,
    hungryAfterSecDefault: Math.round(form.hungryAfterHours * 3600),
    canSizeMg: Math.round(form.canSizeGrams * 1000),
  };
  const patch: Record<string, unknown> = {};
  for (const k of Object.keys(next) as Array<keyof HouseSettings>) if (next[k] !== current[k]) patch[k] = next[k];
  return patch as HousePatch;
}
```

```ts
/**
 * Upload sink (spec §4.6): web log lines reach the house's persisted
 * feed so another phone's crash is visible in this phone's console.
 * Batches of ≤ 50 every 30 s while visible; errors flush at once;
 * nothing is sent while signed out; a failed batch is retried later.
 */
import type { LogEntry, LogSink } from "@feedme2/shared";

export const UPLOAD_INTERVAL_MS = 30_000;
const BATCH = 50;
const MAX_QUEUE = 500;

interface Deps {
  send: (batch: LogEntry[]) => Promise<void>;
  isSignedIn: () => boolean;
  now: () => number;
  /** Returns a cancel function. Default: a repeating timer, paused while hidden. */
  schedule: (fn: () => void) => () => void;
}

export function createUploadSink(deps: Deps): LogSink & { flush(): Promise<void>; stop(): void } {
  let queue: LogEntry[] = [];
  let flushing: Promise<void> | null = null;
  let due = false;

  const cancel = deps.schedule(() => { due = true; void sink.flush(); });

  const sink = {
    write(entry: LogEntry): void {
      if (!deps.isSignedIn()) return;
      // Never upload an entry about uploading: recursion.
      if (entry.msg.startsWith("log upload")) return;
      queue.push(entry);
      if (queue.length > MAX_QUEUE) queue = queue.slice(-MAX_QUEUE);
      if (entry.level === "error") { due = true; void sink.flush(); }
    },
    flush(): Promise<void> {
      if (flushing) return flushing;
      if (!due || queue.length === 0 || !deps.isSignedIn()) { due = false; return Promise.resolve(); }
      flushing = (async () => {
        while (queue.length > 0) {
          const batch = queue.slice(0, BATCH);
          try {
            await deps.send(batch);
            queue = queue.slice(batch.length);
          } catch {
            break; // keep the batch; the next timer retries
          }
        }
        due = false;
      })().finally(() => { flushing = null; });
      return flushing;
    },
    stop: () => cancel(),
  };
  return sink;
}

/** Browser scheduler: every UPLOAD_INTERVAL_MS while the tab is visible. */
export function visibleInterval(fn: () => void): () => void {
  const id = window.setInterval(() => { if (document.visibilityState === "visible") fn(); }, UPLOAD_INTERVAL_MS);
  const onHide = () => { if (document.visibilityState === "hidden") fn(); };
  document.addEventListener("visibilitychange", onHide);
  return () => { window.clearInterval(id); document.removeEventListener("visibilitychange", onHide); };
}
```

```tsx
/** Client buffer + server feed, de-duplicated by (clientId, ts, msg) since
 * this phone's own uploads come back from the server too. */
export function mergeFeeds(client: LogEntry[], server: LogEntry[], myClientId: string): LogEntry[] {
  const seen = new Set<string>();
  const out: LogEntry[] = [];
  for (const e of [...client.map((c) => ({ ...c, clientId: myClientId })), ...server]) {
    const key = `${e.clientId ?? "-"}|${e.ts}|${e.msg}`;
    if (seen.has(key)) continue;
    seen.add(key);
    out.push(e);
  }
  return out.sort((a, b) => b.ts - a.ts);
}
```

```ts
/**
 * Skip unless the target has test auth — but with E2E_REQUIRE_AUTH=1
 * a skip is a failure. A preview job once reported green while
 * skipping most of the suite; this is the guard against that.
 */
export async function requireTestAuth(page: Page): Promise<void> {
  if (await testAuthEnabled(page)) return;
  if (process.env["E2E_REQUIRE_AUTH"] === "1") throw new Error("test auth is not enabled on the target and E2E_REQUIRE_AUTH=1");

export async function signInAsTestHouse(page: Page, houseName: string): Promise<void> {
  const res = await page.request.post("/api/auth/test-login", { data: { houseName } });
  if (res.status() !== 200) throw new Error(`test-login failed: ${res.status()}`);
  const tokens = (await res.json()) as { refreshToken: string; house: unknown };
  await page.goto("/login");
  await page.evaluate(({ refreshToken, house }) => {
    localStorage.setItem("feedme2:refresh", refreshToken);
    localStorage.setItem("feedme2:house", JSON.stringify(house));
  }, tokens);
  await page.goto("/");
}
```
