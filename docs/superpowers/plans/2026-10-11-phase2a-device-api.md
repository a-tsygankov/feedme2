# Phase 2a: Device API + Simulator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Everything a paired device needs from the backend — pairing, device tokens, the one-read state payload with ETag, device feedings/heartbeat/logs — plus the web app's Devices section and a TypeScript device simulator that drives a full-system e2e, so the firmware plan (Phase 2b) can be built against a live, tested API.

**Architecture:** New migration `0002` adds `devices` and `pending_pairings`. Device auth is a 365-day HS256 JWT (`typ:"device"`) checked by `requireDevice()`, which also enforces `revoked_at`. Device routes live under `/api/device/*` and `/api/pair/*`; they reuse `FeedingsRepo.createMany` (origin `device`) and `LogsRepo.insertMany` (source `device`), so device data flows through the same validation, denormalisation and console as web data. `tools/device-sim` is a workspace package exposing a `DeviceSim` class and a CLI; the Playwright e2e pairs a simulated device through the real UI.

**Tech Stack:** Hono 4, Drizzle 0.36 on D1, hono/jwt, zod (shared contracts), vitest-pool-workers; React 18 + react-query (webapp); Node 22 + tsx (device-sim); Playwright (Pixel 7).

**Spec:** `docs/superpowers/specs/2026-09-20-feedme2-design.md` — §1.1 Device entity, §1.2, §1.4 "device receives all settings", §3.1 (`devices`, `pending_pairings`), §3.2 device tokens, §3.3 device routes, §3.4 cron, §4.6 console device filter, §5.3 sync contract, §5.7 item 3 (device simulator), §7 Phase 2 exit test.

## Global Constraints

- Integers only in D1 (epoch-ms, milligrams); client-generated ids; every query scoped by `house_id` from the auth middleware only (CLAUDE.md, spec §3).
- Device id: 32 lowercase hex chars (spec §3.1 `devices.id (32-hex)`), generated by the device from its MAC + random; the server never generates it.
- Device token: HS256 JWT `{typ:"device", sub: houseId, did: deviceId, iat, exp}` with `exp = iat + 365 d` (spec §3.2); Bearer only; revocation via `devices.revoked_at`.
- Pair code: 6 decimal digits, valid 10 minutes, one active pairing per device (spec §5.2 "Pair (QR + 6-digit code)").
- `/api/device/state` is the only device read and carries everything (spec §3.3); it returns an `ETag` and honours `If-None-Match` with 304.
- Error bodies: validation `{error:"invalid_request", issues:[{path,message}]}`; others `{error:"<snake_case>"}` (CLAUDE.md).
- Versioning: `shared/` changes bump webapp + worker; a new file in `backend/migrations/` is the schema bump; `tools/` is not a tier. Never edit a migration in place once merged (0001 is merged).
- Commit style `type(scope): …` lowercase, trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Stage by explicit pathspec only.
- Playwright project is Pixel 7; signed-in e2e specs call `requireTestAuth` (test-login exists only when `ENVIRONMENT` is `development`/`test`).

## Review Focus

1. **A device whose clock is wrong** (RTC at 1970 before SNTP, or hours ahead) posts feedings: a person expects the feeding to land "now", not to vanish or to show the cat as fed in 2050. Pinned in Task 7 (device route clamps `fedAt` into `[now − 7 d, now + 5 min]` and reports `clamped`).
2. **A pair code entered twice, or after the device gave up**: the second confirm must not silently re-pair or create a second device row. Pinned in Task 4 (second confirm → 409 `pair_code_used`; expired → 404 `pair_code_unknown`).
3. **A forgotten (revoked) device keeps its token**: every device route must answer 401 and must not refresh `last_seen_at`. Pinned in Task 3 (`requireDevice` tests) and Task 5 (DELETE then state → 401).
4. **The ETag must change when anything the device displays changes** (cat renamed, deleted, re-ordered, settings changed, feeding logged from the web) **and must not change merely because time passed**. Pinned in Task 6.
5. **A device re-paired to another house** (sold, or the house was deleted and re-created): the device id already exists in another house. Expected: the move succeeds only if the old pairing was revoked; otherwise 409 `device_in_use`. Pinned in Task 4.

```sql
-- Phase 2 (spec §3.1): paired devices and the pairing handshake.
-- No ON DELETE clauses: devices are revoked (revoked_at), never hard-deleted,
-- so feedings keep a valid device_id for history.

CREATE TABLE devices (
  id            TEXT    PRIMARY KEY CHECK (length(id) = 32 AND id = lower(id) AND id NOT GLOB '*[^0-9a-f]*'),
  house_id      TEXT    NOT NULL REFERENCES houses(id),
  name          TEXT    NOT NULL,
  hw_model      TEXT    NOT NULL,
  fw_version    TEXT    NOT NULL,
  last_seen_at  INTEGER,
  battery_pct   INTEGER CHECK (battery_pct IS NULL OR (battery_pct >= 0 AND battery_pct <= 100)),
  reset_reason  TEXT,
  -- Phase 3: install approved OTA updates on the timer wake without asking.
  auto_install  INTEGER NOT NULL DEFAULT 0 CHECK (auto_install IN (0, 1)),
  created_at    INTEGER NOT NULL,
  modified_at   INTEGER NOT NULL,
  revoked_at    INTEGER
);
CREATE INDEX devices_house ON devices (house_id);

-- One handshake per device at a time: POST /api/pair/start replaces the
-- row. device_token is held in plaintext only until the device collects
-- it or the row expires (10 min); the cron deletes expired rows.
CREATE TABLE pending_pairings (
  device_id     TEXT    PRIMARY KEY CHECK (length(device_id) = 32),
  pair_code     TEXT    NOT NULL CHECK (length(pair_code) = 6),
  hw_model      TEXT    NOT NULL,
  fw_version    TEXT    NOT NULL,
  requested_at  INTEGER NOT NULL,
  expires_at    INTEGER NOT NULL CHECK (expires_at > requested_at),
  house_id      TEXT    REFERENCES houses(id),
  confirmed_at  INTEGER,
  device_token  TEXT,
  delivered_at  INTEGER,
  cancelled_at  INTEGER
);
CREATE UNIQUE INDEX pending_pairings_code ON pending_pairings (pair_code);
CREATE INDEX pending_pairings_expires ON pending_pairings (expires_at);
```

```ts
 * Device-facing contracts (spec §3.2–3.3, §5.3). The firmware's JSON

import { CatSchema, FeedingCreateSchema, HouseSettingsSchema, LogsUploadBodySchema } from "./api.ts";

export const DeviceIdSchema = z.string().regex(DEVICE_ID_RE, "32 lowercase hex chars");
export const PAIR_CODE_RE = /^\d{6}$/;
export const PairCodeSchema = z.string().regex(PAIR_CODE_RE, "6 digits");
export const HwModelSchema = z.enum(["crowpanel-1.28", "simulator", "device-sim"]);
```

```ts
/**
 * Device tokens (spec §3.2): a 365-day HS256 JWT issued once at pairing.
 * Same key as house access tokens, kept apart by `typ`; revocation is
 * the devices.revoked_at column, checked by requireDevice on every call.
 */
import { sign, verify } from "hono/jwt";

export const DEVICE_TTL_SEC = 365 * 24 * 60 * 60;
const IAT_SKEW_SEC = 5;
const MIN_SECRET_LENGTH = 32;

export async function signDeviceToken(houseId: string, deviceId: string, secret: string, nowMs: number = Date.now()): Promise<string> {
  if (secret.length < MIN_SECRET_LENGTH) throw new Error("AUTH_SECRET must be at least 32 characters");
  const nowSec = Math.floor(nowMs / 1000);
  return sign({ typ: "device", sub: houseId, did: deviceId, iat: nowSec - IAT_SKEW_SEC, exp: nowSec + DEVICE_TTL_SEC }, secret, "HS256");
}

export async function verifyDeviceToken(token: string, secret: string): Promise<{ houseId: string; deviceId: string } | null> {
  try {
    const p = await verify(token, secret, "HS256");
    if (p["typ"] !== "device" || typeof p["sub"] !== "string" || typeof p["did"] !== "string") return null;
    return { houseId: p["sub"], deviceId: p["did"] };
  } catch {
    return null;
  }
}
```

```ts
import { and, asc, eq, isNull } from "drizzle-orm";
import type { Device, DevicePatch, HwModel } from "@feedme2/shared";

type Row = typeof devices.$inferSelect;

export function toApiDevice(r: Row): Device {
  return {
    id: r.id, houseId: r.houseId, name: r.name, hwModel: r.hwModel as HwModel, fwVersion: r.fwVersion,
    lastSeenAt: r.lastSeenAt, batteryPct: r.batteryPct, resetReason: r.resetReason,

  };

/** How often a device call refreshes last_seen_at; the heartbeat always does. */
export const TOUCH_INTERVAL_MS = 60_000;

export class DevicesRepo {
  constructor(private readonly db: Db) {}

  getAny(id: string): Promise<Row | undefined> {
    return this.db.query.devices.findFirst({ where: eq(devices.id, id) });
  }
  /** Live device of this house (revoked excluded). */
  get(houseId: string, id: string): Promise<Row | undefined> {
    return this.db.query.devices.findFirst({ where: and(eq(devices.houseId, houseId), eq(devices.id, id), isNull(devices.revokedAt)) });
  }
  list(houseId: string): Promise<Row[]> {
    return this.db.query.devices.findMany({ where: and(eq(devices.houseId, houseId), isNull(devices.revokedAt)), orderBy: [asc(devices.createdAt), asc(devices.id)] });
  }
  /** Pairing confirmed: create, or re-attach a revoked device to (possibly another) house. */
  async upsertPaired(row: { id: string; houseId: string; name: string; hwModel: string; fwVersion: string }, nowMs: number): Promise<Row> {
    await this.db
      .insert(devices)
      .values({ ...row, autoInstall: 0, createdAt: nowMs, modifiedAt: nowMs, lastSeenAt: nowMs, revokedAt: null })
      .onConflictDoUpdate({
        target: devices.id,
        set: { houseId: row.houseId, name: row.name, hwModel: row.hwModel, fwVersion: row.fwVersion, modifiedAt: nowMs, lastSeenAt: nowMs, revokedAt: null, batteryPct: null, resetReason: null },
      });
    return (await this.getAny(row.id))!;
  }
  async touch(id: string, nowMs: number, patch: Partial<Pick<Row, "fwVersion" | "batteryPct" | "resetReason">> = {}): Promise<void> {
    await this.db.update(devices).set({ lastSeenAt: nowMs, ...patch }).where(eq(devices.id, id));
  }
  async update(houseId: string, id: string, patch: DevicePatch, nowMs: number): Promise<Row | undefined> {
    const set: Partial<typeof devices.$inferInsert> = { modifiedAt: nowMs };
    if (patch.name !== undefined) set.name = patch.name;
    if (patch.autoInstall !== undefined) set.autoInstall = patch.autoInstall ? 1 : 0;
    await this.db.update(devices).set(set).where(and(eq(devices.houseId, houseId), eq(devices.id, id), isNull(devices.revokedAt)));
    return this.get(houseId, id);
  }
  /** Idempotent: revoking twice is fine; returns false only when the device is not this house's. */
  async revoke(houseId: string, id: string, nowMs: number): Promise<boolean> {
    const row = await this.db.query.devices.findFirst({ where: and(eq(devices.houseId, houseId), eq(devices.id, id)) });
    if (!row) return false;
    if (row.revokedAt === null) await this.db.update(devices).set({ revokedAt: nowMs, modifiedAt: nowMs }).where(eq(devices.id, id));
    return true;
  }
}
```

```ts
import type { MiddlewareHandler } from "hono";
import type { Bindings } from "../env.ts";
import { verifyDeviceToken } from "../auth/device-tokens.ts";
import { db } from "../db/client.ts";
import { DevicesRepo, TOUCH_INTERVAL_MS } from "../repos/devices.ts";
import { clock } from "../auth/tokens.ts";

export type DeviceVars = { Variables: { houseId: string; deviceId: string } };

/**
 * Bearer device token → c.var.houseId + c.var.deviceId. The token says
 * which device; the devices row says whether it is still welcome
 * (revoked_at) and in which house (a re-paired device's old token names
 * the old house and must die). Uniform 401s, like requireHouse.
 */
export function requireDevice(): MiddlewareHandler<{ Bindings: Bindings } & DeviceVars> {
  return async (c, next) => {
    const token = /^Bearer\s+(\S+)\s*$/i.exec(c.req.header("Authorization") ?? "")?.[1] ?? "";
    const claims = token ? await verifyDeviceToken(token, c.env.AUTH_SECRET) : null;
    if (!claims) return c.json({ error: "unauthorized" }, 401);
    const repo = new DevicesRepo(db(c.env.DB));
    const row = await repo.getAny(claims.deviceId);
    if (!row || row.revokedAt !== null || row.houseId !== claims.houseId) return c.json({ error: "unauthorized" }, 401);
    c.set("houseId", row.houseId);
    c.set("deviceId", row.id);
    const now = clock.now();
    if (row.lastSeenAt === null || now - row.lastSeenAt >= TOUCH_INTERVAL_MS) await repo.touch(row.id, now);
    await next();
  };
}
```

```ts
import { eq, lt } from "drizzle-orm";
import type { Db } from "../db/client.ts";
import { pendingPairings } from "../db/schema.ts";

export const PAIR_TTL_MS = 10 * 60_000;
export const PAIR_POLL_SEC = 3;

function randomCode(): string {
  // 100000–999999 so the code never starts with 0 (people drop leading zeros).
  const n = 100_000 + (crypto.getRandomValues(new Uint32Array(1))[0]! % 900_000);
  return String(n);
}

export class PairingsRepo {
  constructor(private readonly db: Db) {}

  findByDevice(deviceId: string) {
    return this.db.query.pendingPairings.findFirst({ where: eq(pendingPairings.deviceId, deviceId) });
  }
  findByCode(code: string) {
    return this.db.query.pendingPairings.findFirst({ where: eq(pendingPairings.pairCode, code) });
  }

  /** One handshake per device: a new start replaces the old row (and its code). */
  async start(deviceId: string, hwModel: string, fwVersion: string, nowMs: number): Promise<{ pairCode: string; expiresAt: number }> {
    const expiresAt = nowMs + PAIR_TTL_MS;
    for (let attempt = 0; attempt < 5; attempt++) {
      const pairCode = randomCode();
      try {
        await this.db
          .insert(pendingPairings)
          .values({ deviceId, pairCode, hwModel, fwVersion, requestedAt: nowMs, expiresAt, houseId: null, confirmedAt: null, deviceToken: null, deliveredAt: null, cancelledAt: null })
          .onConflictDoUpdate({
            target: pendingPairings.deviceId,
            set: { pairCode, hwModel, fwVersion, requestedAt: nowMs, expiresAt, houseId: null, confirmedAt: null, deviceToken: null, deliveredAt: null, cancelledAt: null },
          });
        return { pairCode, expiresAt };
      } catch (err) {
        // UNIQUE on pair_code: another device holds this code right now.
        if (attempt === 4 || !(err instanceof Error && /UNIQUE/i.test(err.message))) throw err;
      }
    }
    throw new Error("unreachable");
  }

  async confirm(deviceId: string, houseId: string, deviceToken: string, nowMs: number): Promise<void> {
    await this.db.update(pendingPairings).set({ houseId, deviceToken, confirmedAt: nowMs }).where(eq(pendingPairings.deviceId, deviceId));
  }
  async markDelivered(deviceId: string, nowMs: number): Promise<void> {
    await this.db.update(pendingPairings).set({ deliveredAt: nowMs }).where(eq(pendingPairings.deviceId, deviceId));
  }
  /** Rows past expiry carry a plaintext token for at most PAIR_TTL_MS; the cron removes them. */
  async pruneExpired(nowMs: number): Promise<number> {
    const r = await this.db.delete(pendingPairings).where(lt(pendingPairings.expiresAt, nowMs));
    return r.meta.changes;
  }
}
```

```ts
    else if (row.confirmedAt !== null && row.deviceToken && row.houseId) {
      const house = await new HousesRepo(d).findById(row.houseId);
      const device = await new DevicesRepo(d).getAny(deviceId);

      if (row.deliveredAt === null) await repo.markDelivered(deviceId, now);
    } else if (row.expiresAt <= now) body = { status: "expired" };
    else body = { status: "pending" };
    return c.json(body);

    const { pairCode, name } = c.req.valid("json");
```

```ts
/**
 * UTC offset of an IANA zone at an instant, in minutes east of UTC. The
 * device has no tz database: it renders local times from this number
 * (spec §1.4 "offset pushed to device") and re-reads it every sync.
 */
export function tzOffsetMin(timeZone: string, nowMs: number): number {
  try {
    const parts = new Intl.DateTimeFormat("en-US", {
      timeZone, hourCycle: "h23", year: "numeric", month: "2-digit", day: "2-digit", hour: "2-digit", minute: "2-digit", second: "2-digit",
    }).formatToParts(new Date(nowMs));
    const get = (t: string) => Number(parts.find((p) => p.type === t)!.value);
    const asUtc = Date.UTC(get("year"), get("month") - 1, get("day"), get("hour"), get("minute"), get("second"));
    return Math.round((asUtc - Math.floor(nowMs / 1000) * 1000) / 60_000);
  } catch {
    return 0;
  }
}
```

```ts
import { Hono } from "hono";
import type { DeviceState } from "@feedme2/shared";
import type { Bindings } from "../env.ts";
import { db, type Db } from "../db/client.ts";
import { clock } from "../auth/tokens.ts";
import { requireDevice, type DeviceVars } from "../middleware/device.ts";
import { CatsRepo, toApiCat } from "../repos/cats.ts";
import { DevicesRepo } from "../repos/devices.ts";
import { HousesRepo, toApiHouse } from "../repos/houses.ts";
import { tzOffsetMin } from "../time.ts";

type Env = { Bindings: Bindings } & DeviceVars;

async function weakEtag(stable: unknown): Promise<string> {
  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(JSON.stringify(stable)));
  return `W/"${[...new Uint8Array(digest)].slice(0, 8).map((b) => b.toString(16).padStart(2, "0")).join("")}"`;
}

/**
 * The one device read (spec §3.3, §5.3): everything the Idle/Amount
 * screens need in one round trip. The ETag covers the parts that change
 * when a person does something (settings, cats, defaults, device name)
 * and deliberately excludes `now` and the tz offset, so a device that
 * polls on its timer gets 304s until something it displays changed.
 */
export async function buildDeviceState(d: Db, houseId: string, deviceId: string, nowMs: number): Promise<{ body: DeviceState; etag: string }> {
  const houseRow = (await new HousesRepo(d).findById(houseId))!;
  const house = toApiHouse(houseRow);
  const device = (await new DevicesRepo(d).getAny(deviceId))!;
  const cats = (await new CatsRepo(d).list(houseId)).map(toApiCat).map((c) => ({
    id: c.id, name: c.name, color: c.color, avatarPose: c.avatarPose, hungryAfterSec: c.hungryAfterSec, sortOrder: c.sortOrder,
    defaultAmountMg: c.defaultAmountMg, defaultEnteredUnit: c.defaultEnteredUnit, defaultEnteredValue: c.defaultEnteredValue, lastFedAt: c.lastFedAt,
  }));
  const stable = { house: { id: house.id, name: house.name, settings: house.settings }, device: { id: device.id, name: device.name }, cats };
  const etag = await weakEtag(stable);
  const body: DeviceState = {
    house: { ...stable.house, tzOffsetMin: tzOffsetMin(house.settings.timezone, nowMs) },
    device: stable.device,
    cats,
    now: nowMs,
    syncIntervalSec: house.settings.syncIntervalSec,
    sleepTimeoutSec: house.settings.sleepTimeoutSec,
  };
  return { body, etag };
}

export const deviceRouter = new Hono<Env>()
  .use("*", requireDevice())
  .get("/state", async (c) => {
    const { body, etag } = await buildDeviceState(db(c.env.DB), c.var.houseId, c.var.deviceId, clock.now());
    c.header("ETag", etag);
    c.header("Cache-Control", "no-store");
    if (c.req.header("if-none-match") === etag) return c.body(null, 304);
    return c.json(body);
  });
```

```ts
export const FED_AT_MAX_PAST_MS = 7 * 24 * 60 * 60 * 1000;
export const FED_AT_MAX_FUTURE_MS = 5 * 60 * 1000;
/** Devices have no UI to fix a timestamp, so a wrong clock is corrected, not refused (web: fedat_in_future 400). */
export function clampFedAt(fedAt: number, nowMs: number): { fedAt: number; clamped: boolean } {
  const lo = nowMs - FED_AT_MAX_PAST_MS;
  const hi = nowMs + FED_AT_MAX_FUTURE_MS;
  if (fedAt < lo || fedAt > hi) return { fedAt: Math.min(hi, Math.max(lo, fedAt)), clamped: true };
  return { fedAt, clamped: false };
}
```

```ts
export function pairErrorMessage(err: unknown): string {
  if (err instanceof NetworkError) return "Check your connection.";
  if (err instanceof ApiError) {
    const code = typeof err.body === "object" && err.body !== null ? (err.body as { error?: string }).error : undefined;

    if (code === "pair_code_used") return "That code was already used.";
    if (code === "device_in_use") return "That device still belongs to another house. Forget it there first.";

  return "Something went wrong. Try again.";
}
```

```ts
    if (url.pathname === "/api/pair/check") return confirmed ? json({ status: "confirmed", deviceToken: "tok", houseId: "h", houseName: "H", deviceName: "Kitchen" }) : json({ status: "pending" });

    if (url.pathname === "/api/device/heartbeat") return json({ now: Date.now() });
    return json({ error: "not_found" }, 404);
  };
  return { fetchFn, calls, confirm: () => { confirmed = true; }, bumpEtag: () => { etag = 'W/"0000000000000002"'; }, failNext: (s: number) => { failNext = s; }, pairings: () => pairings };
}
```

```ts
/**
 * A fake CrowPanel that speaks the device API exactly (spec §5.7 item 3),
 * using the shared zod contracts so a server change breaks this before
 * it breaks the firmware. Used by the Playwright system e2e and by hand
 * from the CLI.
 */
import {
  DeviceFeedingsResponseSchema, DeviceStateSchema, HeartbeatResponseSchema, PairCheckResponseSchema, PairStartResponseSchema,
  type DeviceFeedingCreate, type DeviceState, type FoodUnit, type HwModel, type LogUploadEntry, type PairCheckResponse, type PairStartResponse,
} from "@feedme2/shared";

export class SimError extends Error {
  constructor(readonly status: number, readonly body: unknown, message = `api ${status}`) {
    super(message);
    this.name = "SimError";
  }
}

export interface SimSnapshot {
  deviceId: string;
  token: string | null;
  houseId: string | null;
  etag: string | null;
  state: DeviceState | null;
  queue: DeviceFeedingCreate[];
  logs: LogUploadEntry[];
}

export interface SimOptions {
  apiBase: string;
  deviceId?: string;
  hwModel?: HwModel;
  fwVersion?: string;
  fetchFn?: typeof fetch;
  now?: () => number;
}

export interface SyncSummary {
  feedingsSent: number;
  feedingsAccepted: number;
  clamped: number;
  logsSent: number;
  stateChanged: boolean;
  heartbeat: boolean;
  stoppedBy?: string;
}

const hex32 = () => crypto.randomUUID().replace(/-/g, "");

export class DeviceSim {
  readonly deviceId: string;
  private readonly apiBase: string;
  private readonly hwModel: HwModel;
  private readonly fwVersion: string;
  private readonly fetchFn: typeof fetch;
  private readonly now: () => number;
  private readonly bootedAt: number;
  private snap: SimSnapshot;

  constructor(opts: SimOptions, snap?: SimSnapshot) {
    this.apiBase = opts.apiBase.replace(/\/$/, "");
    this.hwModel = opts.hwModel ?? "device-sim";
    this.fwVersion = opts.fwVersion ?? "0.2.0";
    this.fetchFn = opts.fetchFn ?? fetch;
    this.now = opts.now ?? Date.now;
    this.bootedAt = this.now();
    this.deviceId = snap?.deviceId ?? opts.deviceId ?? hex32();
    this.snap = snap ?? { deviceId: this.deviceId, token: null, houseId: null, etag: null, state: null, queue: [], logs: [] };
  }

  static fromSnapshot(opts: SimOptions, snap: SimSnapshot): DeviceSim {
    return new DeviceSim(opts, snap);
  }

  snapshot(): SimSnapshot {
    return structuredClone(this.snap);
  }

  private async call(path: string, init: RequestInit & { auth?: boolean } = {}): Promise<Response> {
    const headers = new Headers(init.headers);
    if (init.body && !headers.has("content-type")) headers.set("content-type", "application/json");
    if (init.auth !== false && this.snap.token) headers.set("authorization", `Bearer ${this.snap.token}`);
    let res: Response;
    try {
      res = await this.fetchFn(`${this.apiBase}${path}`, { ...init, headers, signal: AbortSignal.timeout(15_000) });
    } catch (err) {
      throw new SimError(0, null, `network: ${(err as Error).message}`);
    }
    if (!res.ok && res.status !== 304) {
      let body: unknown = null;
      try { body = await res.json(); } catch { /* text or empty */ }
      throw new SimError(res.status, body);
    }
    return res;
  }

  async pairStart(): Promise<PairStartResponse> {
    const r = await this.call("/api/pair/start", { method: "POST", auth: false, body: JSON.stringify({ deviceId: this.deviceId, hwModel: this.hwModel, fwVersion: this.fwVersion }) });
    return PairStartResponseSchema.parse(await r.json());
  }

  async pairCheck(): Promise<PairCheckResponse> {
    const r = await this.call("/api/pair/check", { method: "POST", auth: false, body: JSON.stringify({ deviceId: this.deviceId }) });
    const body = PairCheckResponseSchema.parse(await r.json());
    if (body.status === "confirmed") {
      this.snap.token = body.deviceToken;
      this.snap.houseId = body.houseId;
    }
    return body;
  }

  async pairUntilConfirmed({ timeoutMs = 120_000, intervalMs = 500 }: { timeoutMs?: number; intervalMs?: number } = {}): Promise<void> {
    const deadline = Date.now() + timeoutMs;
    while (Date.now() < deadline) {
      const r = await this.pairCheck();
      if (r.status === "confirmed") return;
      if (r.status === "expired" || r.status === "unknown") throw new SimError(410, r, `pairing ${r.status}`);
      await new Promise((f) => setTimeout(f, intervalMs));
    }
    throw new SimError(408, null, "pairing timed out");
  }

  async fetchState(): Promise<{ changed: boolean; state: DeviceState }> {
    const r = await this.call("/api/device/state", { headers: this.snap.etag ? { "if-none-match": this.snap.etag } : {} });
    if (r.status === 304) {
      if (!this.snap.state) throw new SimError(304, null, "304 without a cached state");
      return { changed: false, state: this.snap.state };
    }
    const state = DeviceStateSchema.parse(await r.json());
    this.snap.state = state;
    this.snap.etag = r.headers.get("etag");
    return { changed: true, state };
  }

  /** Queue a feeding like a knob press would; `cat` is a name or an id from the last state. */
  feed(cat: string, amountMg?: number, entered?: { unit: FoodUnit; value: string }): DeviceFeedingCreate {
    const c = this.snap.state?.cats.find((x) => x.id === cat || x.name === cat);
    if (!c) throw new Error(`unknown cat ${cat}`);
    const mg = amountMg ?? c.defaultAmountMg ?? 40_000;
    const e = entered ?? (amountMg === undefined && c.defaultEnteredUnit && c.defaultEnteredValue ? { unit: c.defaultEnteredUnit, value: c.defaultEnteredValue } : { unit: "g" as const, value: String(Math.round(mg / 1000)) });
    const item: DeviceFeedingCreate = { id: crypto.randomUUID(), catId: c.id, fedAt: this.now(), amountMg: mg, enteredUnit: e.unit, enteredValue: e.value };
    this.snap.queue.push(item);
    return item;
  }

  log(level: LogUploadEntry["level"], msg: string, data?: Record<string, unknown>): void {
    this.snap.logs.push({ ts: this.now(), level, msg, ...(data ? { data } : {}) });
    if (this.snap.logs.length > 500) this.snap.logs.splice(0, this.snap.logs.length - 500);
  }

  async heartbeat(): Promise<void> {
    const r = await this.call("/api/device/heartbeat", { method: "POST", body: JSON.stringify({ fwVersion: this.fwVersion, uptimeSec: Math.floor((this.now() - this.bootedAt) / 1000), resetReason: "SIM", freeHeap: 200_000 }) });
    HeartbeatResponseSchema.parse(await r.json());
  }

  /** Spec §5.3: feedings → logs → state → heartbeat. A transport or 5xx failure stops the round and keeps the queues. */
  async syncRound(): Promise<SyncSummary> {
    const s: SyncSummary = { feedingsSent: 0, feedingsAccepted: 0, clamped: 0, logsSent: 0, stateChanged: false, heartbeat: false };
    const transient = (e: unknown) => e instanceof SimError && (e.status === 0 || e.status >= 500 || e.status === 408 || e.status === 429);
    try {
      while (this.snap.queue.length > 0) {
        const batch = this.snap.queue.slice(0, 100);
        const r = await this.call("/api/device/feedings", { method: "POST", body: JSON.stringify(batch) });
        const body = DeviceFeedingsResponseSchema.parse(await r.json());
        s.feedingsSent += batch.length;
        s.feedingsAccepted += body.accepted.length;
        s.clamped += body.clamped.length;
        this.snap.queue.splice(0, batch.length);
      }
      while (this.snap.logs.length > 0) {
        const batch = this.snap.logs.slice(0, 50);
        await this.call("/api/device/logs", { method: "POST", body: JSON.stringify(batch) });
        s.logsSent += batch.length;
        this.snap.logs.splice(0, batch.length);
      }
      s.stateChanged = (await this.fetchState()).changed;
      await this.heartbeat();
      s.heartbeat = true;
    } catch (e) {
      if (!transient(e)) throw e;
      s.stoppedBy = (e as SimError).message;
    }
    return s;
  }
}
```
